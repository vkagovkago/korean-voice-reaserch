한 줄 요약

폐 → 성대(또는 새의 명관) → 가지 친 성도 → 입술·코까지 공기 흐름을 FDTD로 시뮬레이션해 목소리를 만든다. 녹음된 소리를 재생하지 않고, 혀·턱·입술을 움직이면 그 모양에서 소리가 계산된다.

소리가 나오는 경로

핵심 구성요소

기도 음향 (FDTD)

스태거드 그리드 전송선. 비강·피리형와·두 기관지 등 분기, 벽 진동, 난류 잡음, 입술 방사를 한 틀에서 처리.

성대 음원

기본은 성문 면적 펄스(피치 정확). 고급 모드는 2질량 성대(Ishizaka–Flanagan) 자기진동 모델. 지터·비브라토·보컬 프라이·가성 지원.

조음 제스처

조음음운론 방식. 음소 = 제스처 묶음, 조음기관은 임계감쇠 2차 동역학으로 움직여 동시조음이 자연히 생김.

체형 블렌드

남성·여성·아이 체형을 연속으로 섞음. 포먼트 왜곡이 아니라 해부학적 스케일링.

동물 도감

명금류(2음원 명관), 물범, 악어, 코끼리. 같은 토폴로지에 종별 파라미터.

결정론 · 실시간 안전

같은 코드가 네이티브 테스트·CLI·웹에서 동일하게 돌아감.

기능

모드설명
Play머리 단면에서 혀·입술·턱 드래그, 모음 패드, 키보드, Web MIDI
Speak영어 텍스트(CMUdict) 또는 IPA → 제스처·운율. 제스처 스코어와 자음표 표시
Sing가사를 분위기에 맞는 곡조로 노래. 9:16 영상 녹화. 한국어(한글) · 영어 · 러시아어 가사 지원, 한국어 음운 규칙 적용
Beatbox패드 + 스텝 시퀀서, 모든 드럼이 조음 제스처
Bestiary새, 물범, 악어, 코끼리
Duet?show=<id> 로 두 개의 3D 머리가 미리 렌더된 노래를 재생

실행 방법

bun install
bun run dev      # wasm 빌드 후 Vite, 127.0.0.1:5317
bun run test     # wasm 빌드 + cargo test + bun test

Rust(wasm32-unknown-unknown 타깃)와 Bun 필요. AudioWorklet 때문에 localhost 또는 HTTPS에서 열어야 함.

# 오프라인 렌더 / 측정 (CLI)
cargo run --release -p chimera-cli -- render speech|text|song|notes|beatbox|creature|vowels
cargo run --release -p chimera-cli -- diagnose
cargo run --release -p chimera-cli -- compare csd   # 실제 가수와 비교
cargo run --release -p chimera-cli -- compare tsp   # 실제 화자 23명과 비교

범위 밖 / 미구현

DAW·시퀀서, 라이트 테마, MPE, 다중 화자 대화는 지금 목표 아님. 더 많은 동물, 앱 내 WAV 내보내기 등은 아직 없음. 2질량 성대는 설계상 있으나 기본은 파라미터 성문 모델.
